## Description
A console application in Python 3 for a hotel. The user can view available rooms, book a room for a guest, cancel a booking and generate a bill. Bookings are saved in bookings.txt.

## Concepts Used
Dictionaries, Lists, Functions, File Handling

## Room Rates (per night)
- 101 Single: Rs. 2000
- 102 Double: Rs. 3500
- 201 Suite: Rs. 6000

## Features
- View available rooms
- Book a room (nights must be 1 to 30)
- Prevent double booking
- Cancel a booking
- Generate bill: rate x nights + 12% GST
- Bookings saved in bookings.txt and loaded at program start

## How to Run
1. Install Python 3
2. Open a terminal in the Codebase folder
3. Run: python hotel_booking.py

## Menu
1. View available rooms
2. Book a room
3. Generate bill
4. Cancel booking
5. Exit
